ACTIVE CORRECTNESS FINDING THRESHOLD


Create an `ACTIVE_CORRECTNESS` finding only when current evidence supports every Finding Schema requirement:

1. an identifiable current invariant, contract, lifecycle rule, transition rule, ownership rule, or artifact rule;
2. a concrete current repository code path or artifact;
3. current evidence for the violation;
4. a realistic trigger or set of preconditions; and
5. a behaviorally meaningful failure mode.


For each active finding, use the complete Active Correctness record from `Schemas/Finding Schema.md`. In particular, assign a stable Finding ID; link all affected Object IDs and Search-space ID/version; state domain, classification, severity, invariant, evidence, repository anchors, complete proof chain, trigger, reachability, failure mode, observable consequence, confidence, remediation state, verification state, residual risk, derived-work references, and any upward-invalidation reference.


Use the shared severity semantics exactly:

- `P0`: current evidence supports catastrophic, dangerous, broadly corrupting, release-blocking, or highly likely core-path failure;
- `P1`: current evidence supports a behaviorally meaningful defect, stale/incorrect state risk, invalid contract, or concrete current fragility requiring normal correctness remediation; and
- `P2`: current evidence supports a real but lower-impact, narrower, or less frequently triggered current correctness defect or risk under evidenced preconditions.


`P2` is not a future hazard bucket.


Do not report style preferences, cleanup, unfamiliarity, complexity alone, speculative interleavings, theoretical future issues, missing tests alone, optional hardening, observability improvements, or “might become a bug later” concerns as active correctness findings.


If current repository evidence is insufficient or resolution depends on hosted, provider, browser, production, chain, live-system, or manual evidence, use `UNVERIFIABLE` or `EXTERNAL_BOUNDARY` as the shared rules require. Do not lower the finding threshold because an area is high risk.
